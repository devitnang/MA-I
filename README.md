A sample command-line application with an entrypoint in `bin/`, library code
in `lib/`, and example unit test in `test/`.
## Getting Started

For help getting started with Dart, view the
[online documentation](https://dart.dev/guides), which offers tutorials,
samples, a guidance on mobile development, and a full API reference.

## Usage

1. Install dependencies:
   ```
   dart pub get
   ```

2. Run the application:
   ```
   dart run bin/test_project.dart
   ```

3. Run tests:
   ```
   dart test
